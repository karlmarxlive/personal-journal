# MyJournal 1.0.2 — оптимизация прокрутки

Изменения применяются к черновикам и запечатанным записям. Формат базы данных и сохранённых фотографий не меняется.

## Что изменено

- Фото декодируются по размеру отображения в фоне; максимум две задачи одновременно. Загрузка включается в пределах экрана и одного экрана запаса сверху и снизу. Далёкие блоки освобождают ссылку на изображение, сохраняя размеры страницы.
- Общий кеш ограничен `min(32 МиБ, maxMemory / 8)`. Удаление из кеша не уничтожает bitmap, который ещё отображается. При сигнале Android о сокращении памяти кеш очищается.
- Масштабирование запрашивает более подробное изображение. Ошибка чтения имеет отдельное сообщение. Устаревший запрос отменяется и не подменяет новую фотографию.
- Границы символов и геометрия блоков сохраняются в координатах страницы. Прокрутка переиспользует готовый снимок геометрии; редактирование и перемещение блоков обновляют его.
- Подготовленные рукописные штрихи переиспользуются без повторного хеширования текста и данных штрихов на каждом кадре. Кеш учитывает изменения самих штрихов, их привязок, темы и режима PDF.

## Проверяемые сценарии

| Проверка | Критерий |
| --- | --- |
| Длинный текст, повторная прокрутка | Снимок геометрии и счётчики расчёта символов не меняются |
| Редактирование первого ответа | Символы пересчитываются у изменённого блока; последующие блоки получают новые координаты |
| 30 фото в обоих режимах | Переходы начало → середина → конец → начало; изображения удерживаются только рядом с экраном |
| Фото | Размеры 50/75/100%, полноэкранный просмотр, запрос разрешения для масштаба 3× |
| Загрузка | Размер декодирования соответствует показу; сохранённый файл имеет прежний SHA-256 |
| Отмена и ошибка | Старый результат не появляется вместо нового; ошибка не меняет размер блока |
| Кеш изображений | Соблюдается лимит памяти; вытеснение не уничтожает видимые изображения |
| 200 рукописных штрихов | 120 повторных обращений не создают штрихи заново; изменение одной привязки обновляет только её результат |
| Регрессии | Хранилище, автосохранение, запечатывание, undo/redo, reflow, экспорт и обрезка содержимого границами экрана |

Итоговые численные результаты, подпись и SHA-256 APK записываются в `dist/verification/report.json` скриптом `scripts/verify-artifact.ps1` после успешного завершения проверок.

## Граница проверки

Автоматические проверки этой версии выполнены только на компьютере по запросу пользователя: 47 тестов прошли, ошибок lint нет (19 предупреждений). Они подтверждают корректность поведения и исключение повторной работы в проверенных сценариях, но не измеряют FPS на физическом телефоне. Автоматическая проверка нативной отрисовки AndroidX Ink для 1.0.2 не проводилась. Полная виртуализация текстовых блоков не вводилась: сохранена непрерывная страница с существующими привязками рисунков.

После установки версии 1.0.2 пользователь подтвердил, что прокрутка стала существенно плавнее и проблема исчезла. Это результат пользовательской проверки; инструментальные замеры времени кадров не выполнялись.
