# Проверка на Android 16 — следующий шаг

Статус: **не выполнена, отложена пользователем 2026-09-05**. При первоначальной проверке ADB список устройств был пуст. Подключение понадобится после подготовки APK.

1. Подключить телефон, включить USB debugging, подтвердить доверие. Проверить `adb devices -l` и `adb shell getprop ro.build.version.sdk` (36).
2. Выполнить `.\scripts\build.ps1 connectedDebugAndroidTest`. Проверить XML в `app/build/outputs/androidTest-results/connected/`. Тесты очищают только отдельный `.debug` package.
3. Холодный старт — календарь. Пустая старая дата не создаёт запись; создать запись за вчера.
4. Ввести многострочные ответы под несколькими вопросами. Вставить фото между абзацами, проверить три размера, ориентацию и прозрачность.
5. Проверить все цвета, толщины 2 и 8 dp, рисование одним пальцем, zoom/pan двумя, отсутствие вращения, возврат в «Текст», системные insets и отмену незаконченного штриха.
6. Нарисовать подчёркивание, обводку, зачёркивание и свободную стрелку. Добавить текст выше; проверить привязки при reflow. Изменить текст внутри диапазона — рисунок должен остаться свободным. Проверить undo/redo.
7. Подождать автосохранения, выполнить `adb shell am force-stop com.nsfr.myjournal.debug`. Снова открыть приложение, продолжить черновик и проверить текст, фото и undo/redo. Отдельно проверить немедленный уход Home после ввода.
8. Изменить вопрос, запечатать запись, создать запись за сегодня и проверить наследование шаблона и архив старой формулировки.
9. В календаре открыть запечатанную запись; убедиться в отсутствии изменения текста, фото, вопросов, чернил и отдельного удаления.
10. Проверить светлую, тёмную и системную темы, контраст чернил и просмотр фото на весь экран.
11. Экспортировать ZIP через системный диалог. Открыть PDF внешним просмотрщиком, проверить A4, даты, многостраничный текст, фотографии, все виды чернил и штрих через границу страницы. Проверить Markdown и относительные пути `media`.
12. Установить `adb install -r .\dist\MyJournal-1.0.0.apk`; проверить `adb shell dumpsys package com.nsfr.myjournal`. Повторить короткий сценарий Room + Ink + экспорт на release с R8. Зафиксировать logcat без исключений приложения, время холодного старта и визуальную плавность.

Не очищать release-данные и не удалять приложение с личными записями при проверке обновлений. Для тестов полной очистки использовать `.debug`.
